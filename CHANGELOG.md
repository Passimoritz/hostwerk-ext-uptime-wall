## 1.3.0

- Empty state with an "Add a check" button that leads to Live → Monitoring. / Leerzustand mit „Prüfung anlegen“.
- Outages are shown on every tile; the history line has a text alternative for screen readers; no crash when the answer has no checks. / Ausfälle sichtbar, Linie mit Textalternative, kein Absturz ohne Prüfungen.
- Error state with "Try again"; refresh pauses while page or dashboard are hidden; numbers in Hostwerk's language; sizes from the design scale. / Fehlerzustand, Pause bei verstecktem Reiter, Design-Skala.
- Area "Monitoring" in the sidebar, shortcut Ctrl+Alt+U, other extensions may add tabs. / Seitenleiste, Kürzel, Reiter für Zusätze.
- German README describes the public status page. / Deutsche README beschreibt die öffentliche Statusseite.
